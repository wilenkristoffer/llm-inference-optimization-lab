# Disk cleanup plan

What this lab has put on disk, which later phase still needs it, and when it
can go. Written 2026-10-22, during Phase 6. Sizes are approximate.

Re-downloading is cheap - the whole Phase 6 ladder took ~50 minutes - so the
rule is to delete as soon as nothing *planned* needs a model, not to hoard
against a maybe.

**Not the lab's, never delete from this list:** every Ollama model that
predates the lab (pulled before 2026-09-11) or was pulled outside it -
`qwen2.5:0.5b/1.5b/3b/7b/14b/32b`, `qwen3:14b`, `qwen2.5vl:*`, `gemma3:*`,
`gemma4:*`, `llama3*`, `moondream`, `nomic-embed-text`. The lab *uses* some of
them, but did not pull them. Same for `~/.jdks`, `~/.m2`, `~/.npm` and
`~/projects` inside WSL.

### The WSL disk does not shrink by itself

WSL stores Ubuntu in one virtual disk,
`%LOCALAPPDATA%\wsl\{534264fb-...}\ext4.vhdx`, currently **79 GB on C:**.
Deleting files inside WSL frees space *inside* it but the file on C: stays
79 GB. After the deletions, compact it:

```
wsl --shutdown
wsl --manage Ubuntu --set-sparse true      # then let it reclaim, or:
# diskpart > select vdisk file="...\ext4.vhdx" > compact vdisk
```

Do this last, once, after Stage 3.
